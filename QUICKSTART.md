# Quickstart

_This project is early in its port — the `decode`/`encode` API isn't
implemented yet (see `CHANGELOG.md` for current status). This guide
will be filled in with a real, verified-to-run example once the
`.dxn` text codec lands._

## Install

```sh
composer require joetjen/dextrin
```

Requires PHP 8.2 or later.
